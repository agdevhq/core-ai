Add tool discovery. With `toolDiscovery` set on `generate` / `stream`, core-ai declares a discovery tool; the model's calls to it arrive as `ToolDiscoveryCall`s in the new `result.discoveryCalls` (never in `toolCalls`; in `parts` as `ToolDiscoveryCallPart`s wrapping them, streamed as one `tool-discovery-call` event), and the application answers each with a `ToolDiscoveryResultMessage` (`discoveryCallId`) listing `ToolSnapshot`s (tool definitions with plain JSON Schema parameters), or no tools and an optional `note` explaining why. Discovered tools are then callable by their real names on every provider and stay declared while their results are in the history. `finishReason: 'tool-calls'` covers pending discovery calls, so loop on `finishReason` and answer both `toolCalls` and `discoveryCalls`. Discovery calls pair with their results per step. Malformed discovery histories, a `note` next to tools, reserved tool names, snapshot names some provider rejects (only letters, digits, underscores, and dashes, starting with a letter or underscore, up to 128 characters), and a `toolChoice` naming a non-caller tool throw `ValidationError` before any provider call, also on `generateObject` / `streamObject`, which declare no discovered tools. Every strict snapshot in the history, including ones a later discovery replaced, is checked against the strict-capable schema contract on every model, and declared without `strict` on models without strict tool support or beyond their `maxStrictTools` or `maxUnionParameters` limit.

**Type change:** `ModelCapabilities` gains a required `tools.toolDiscovery` field (`'native' | 'emulated'`) and `GenerateResult` a required `discoveryCalls` array, so code that builds either by hand must add them. `Message`, `AssistantContentPart`, and `StreamEvent` gain the new members, so exhaustive switches over them must handle them. Adds adapter helpers (`resolveToolDiscovery`, `getEmulatedToolSet`, `emulateToolDiscoveryMessages`, `getStructuredOutputMessages`, and others); `finalizeGenerateResult` and the `request` option of `createChatStream` turn calls to the discovery tool into discovery calls.
